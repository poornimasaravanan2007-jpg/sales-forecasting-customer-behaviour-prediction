# Sales Forecasting and Customer Behaviour Prediction

## Overview
This Python project analyzes historical sales records to identify customer purchasing patterns and estimate future product demand. It helps businesses make informed decisions about inventory planning and sales strategies.

## Features
- Sales trend analysis
- Customer behaviour analysis
- Future sales prediction
- Data visualization

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Google Colab
